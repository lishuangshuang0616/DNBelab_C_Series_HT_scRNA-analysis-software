# C6 Multiplexed Analysis Outputs

The output directory structure for C6 multiplexed single-cell RNA analysis is organized into two primary tiers: **root combined deliverables** for batch-wide quality comparison, and **per-sample dedicated analysis folders** for independent downstream single-cell exploration.

---

## Output Directory Structure <a id="output-directory-structure"></a>

Upon completion, results are archived under `<outdir>/<name>/outs/`:

```text
<outdir>/<name>/outs/
├── <name>_multi_report.html              # Batch multiplexed summary report
└── rna/
    ├── raw_feature_bc_matrix/            # Combined unfiltered expression matrix (MEX)
    ├── raw_feature_bc_matrix.h5          # Combined unfiltered expression matrix (H5)
    ├── filtered_feature_bc_matrix/       # Combined filtered cell matrix (MEX)
    ├── filtered_feature_bc_matrix.h5     # Combined filtered cell matrix (H5)
    ├── filtered_feature_bc_matrix.h5ad   # Combined filtered cell matrix (H5AD, raw counts)
    ├── singlecell.csv.gz                 # Compressed droplet summary (including background)
    ├── metrics_summary.xls               # Experiment-wide summary metrics (TSV)
    ├── oligo.records.bam                 # Shared oligo alignment records (if BAM is enabled)
    ├── unassigned_alignments.bam         # Alignments from unassigned reads (if BAM is enabled)
    ├── multi_sample/                     # Probe assignment and multiplexing metrics
    │   ├── per_sample_metrics.csv        # Cross-sample comparison metrics table
    │   ├── sample_metrics_summary.xls    # Detailed sample-level QC metrics
    │   ├── barcode_assignment_metrics.json # Probe de-multiplexing statistics
    │   └── high_occupancy_metrics.json   # High-occupancy droplet filtering metrics
    └── per_sample_outs/<sample>/         # [Per-sample independent deliverable directory]
        ├── raw_feature_bc_matrix/        # Sample-specific unfiltered matrix
        ├── raw_feature_bc_matrix.h5
        ├── filtered_feature_bc_matrix/   # Sample-specific filtered matrix (MEX)
        ├── filtered_feature_bc_matrix.h5 # Sample-specific filtered matrix (H5)
        ├── filtered_feature_bc_matrix.h5ad # Sample-specific filtered matrix (H5AD)
        ├── <sample>_scRNA_report.html    # Dedicated interactive sample HTML report
        ├── metrics_summary.xls           # Sample-specific metrics table
        ├── <sample>_alignments.bam       # Dedicated sample BAM (with .bai / .csi)
        └── analysis/                     # Dedicated clustering and marker gene analysis
            ├── clustering/               # Graph-based clustering results
            ├── diffexp/                  # Differential expression & marker gene tables
            ├── pca/                      # PCA dimensional reduction coordinates
            ├── tsne/                     # t-SNE visualization coordinates
            └── umap/                     # UMAP visualization coordinates
```

## Detailed Deliverables <a id="detailed-deliverables"></a>

### 1. Batch Multiplexed Summary Report (`<name>_multi_report.html`)
* **Purpose**: Overview of the multiplexed run across all pooled samples.
* **Key Sections**:
  * **Batch Overview**: Summary of cell counts, assigned reads fraction, and sequencing depth across samples;
  * **Library QC**: Shared cDNA and Oligo base quality (Q30), adapter trimming, and valid barcode rates;
  * **Sample Comparison**: Side-by-side interactive bar and scatter plots comparing median genes per cell, median UMI counts, and mitochondrial percentages.

### 2. Root Combined Matrices (`filtered_feature_bc_matrix.*`)
* **Purpose**: Unified count matrices pooling called cells across all biological samples in MEX, H5, and H5AD formats.
* **Design Note**: Preserves raw gene expression counts **without cross-sample joint clustering or UMAP projections**. This prevents uncorrected batch effects from generating spurious clusters, enabling researchers to perform rigorous integration using tools such as Harmony or Scanorama downstream.

### 3. Compressed Droplet Summary (`singlecell.csv.gz`)
Stream-compressed gzip file containing comprehensive metrics for every bead/droplet, including background:

| Column | Description |
| :--- | :--- |
| `cell` | Aggregated cell identifier |
| `reads` | Total transcriptomic reads mapped to the bead/droplet |
| `gene` | Number of distinct genes detected |
| `umi` | Total unique transcript molecules (UMIs) detected |
| `is_cell_barcode` | **True cell flag** (`1` or `True` indicates a called cell; `0` or `False` indicates background) |
| `barcode` | Original cellular barcode with Sample Barcode suffix |

> **Downstream Analysis Tip**: When analyzing this file in Python or R, always filter rows by `is_cell_barcode == 1` to isolate true biological cells.

### 4. Per-Sample Dedicated Subdirectories (`per_sample_outs/<sample>/`)

Each biological sample receives a complete, independent deliverable matching standard single-cell runs:

* **Interactive HTML Report (`<sample>_scRNA_report.html`)**: Sample-specific barcode rank plot, clustering UMAP/t-SNE, and marker gene heatmaps;
* **Independent Matrices**: MEX, H5, and AnnData (H5AD) formatted count matrices containing sample-level clusters;
* **Sample-Specific BAM (`<sample>_alignments.bam`)**: Contains only reads assigned to this sample, ready for direct visualization in IGV.

## Metric Denominators & Interpretation <a id="metric-denominators"></a>

| Metric | Scope & Calculation |
| :--- | :--- |
| **Assigned Reads** | Read pairs assigned to this specific sample based on Sample Barcode matching (not total pooled raw reads) |
| **Mean Reads per Cell** | `Assigned Reads` / `Cells` within the sample (shows N/A if cell count is 0) |
| **Fraction Reads in Cells** | Confident transcriptomic reads in cells divided by all confident reads for valid barcodes in this sample |
| **Mapping Quality** | Evaluated against all reads assigned to the sample |
| **cDNA Valid Barcodes** | Reflects 100% when Assigned Reads > 0 (measures the assigned population) |
| **Library QC (Q30 / Valid UMI)** | Shared across the entire pooled sequencing run; labeled with `cDNA QC scope` in reports |
| **Sample Barcode Valid Rate** | Percentage of Oligo reads matching designed barcode whitelists based on observed statistics |
