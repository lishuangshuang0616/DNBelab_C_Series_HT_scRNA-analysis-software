# C6 多样本分析输出说明

C6 多样本 RNA 分析的交付结构采用**全局合并结果**与**逐样本独立专属分析**分层组织的模式，既支持快速进行批次质控比较，也方便对各个生物学样本开展独立的单细胞下游分析。

---

## 输出目录结构 <a id="输出目录结构"></a>

运行完成后，结果归档在 `<outdir>/<name>/outs/` 目录下：

```text
<outdir>/<name>/outs/
├── <name>_multi_report.html              # 批次多样本汇总报告
└── rna/
    ├── raw_feature_bc_matrix/            # 全局未过滤表达矩阵 (MEX)
    ├── raw_feature_bc_matrix.h5          # 全局未过滤表达矩阵 (H5)
    ├── filtered_feature_bc_matrix/       # 全局有效细胞表达矩阵 (MEX)
    ├── filtered_feature_bc_matrix.h5     # 全局有效细胞表达矩阵 (H5)
    ├── filtered_feature_bc_matrix.h5ad   # 全局有效细胞表达矩阵 (H5AD，无跨样本聚类)
    ├── singlecell.csv.gz                 # 全局液滴明细表 (含背景与零 UMI，流式压缩)
    ├── metrics_summary.xls               # 全局实验汇总指标 (制表符分隔)
    ├── oligo.records.bam                 # 共享 Oligo 比对记录 (启用 BAM 时输出)
    ├── unassigned_alignments.bam         # 未分配样本的读段比对 (启用 BAM 时输出)
    ├── multi_sample/                     # 样本拆分与质控指标
    │   ├── per_sample_metrics.csv        # 各样本核心生信指标对照表
    │   ├── sample_metrics_summary.xls    # 样本级质控汇总明细
    │   ├── barcode_assignment_metrics.json # Sample Barcode 识别与分配统计
    │   └── high_occupancy_metrics.json   # 高占用液滴过滤统计
    └── per_sample_outs/<sample>/         # 【逐样本独立交付目录】
        ├── raw_feature_bc_matrix/        # 该样本未过滤表达矩阵
        ├── raw_feature_bc_matrix.h5
        ├── filtered_feature_bc_matrix/   # 该样本有效细胞表达矩阵 (MEX)
        ├── filtered_feature_bc_matrix.h5 # 该样本有效细胞表达矩阵 (H5)
        ├── filtered_feature_bc_matrix.h5ad # 该样本有效细胞表达矩阵 (H5AD)
        ├── <sample>_scRNA_report.html    # 该样本专属独立交互式 HTML 报告
        ├── metrics_summary.xls           # 该样本专属质控指标表
        ├── <sample>_alignments.bam       # 该样本专属比对 BAM (附带 .bai / .csi)
        └── analysis/                     # 该样本专属聚类与 Marker 分析
            ├── clustering/               # 图聚类分析结果
            ├── diffexp/                  # 差异基因与 Marker 基因表
            ├── pca/                      # PCA 降维坐标与载荷
            ├── tsne/                     # t-SNE 可视化坐标
            └── umap/                     # UMAP 可视化坐标
```

## 核心交付文件详解 <a id="核心交付文件详解"></a>

### 1. 批次多样本汇总报告 (`<name>_multi_report.html`)
* **定位**：整个 C6 混合实验的批次质控总览。
* **主要内容**：
  * **Batch Overview**：展示各个样本的分配细胞数、Assigned Reads 比例与测序深度分布；
  * **Library QC**：共享 cDNA 与 Oligo 文库的碱基质量（Q30）、接头污染及有效 Barcode 比例；
  * **Sample Comparison**：以交互式柱状图与散点图直观对比各个样本的检测基因数（Median Genes per Cell）、UMI 中位数及线粒体比例。

### 2. 全局合并表达矩阵 (`filtered_feature_bc_matrix.*`)
* **定位**：汇集全部样本有效细胞的联合计数矩阵，同时提供 MEX 目录、H5 与 H5AD 格式。
* **特点**：保留干净的原始表达定量，**不附带跨样本的联合降维与无监督聚类**。这避免了将未去除批次效应的多个样本强行联合聚类产生虚假分群，便于用户后续按需选用 Harmony、Scanorama 或 Seurat Integrate 等工具进行严谨的批次校正。

### 3. 全局液滴明细表 (`singlecell.csv.gz`)
采用流式 gzip 压缩格式存储全量微球与液滴数据（含背景噪音液滴）。

| 列名 | 说明 |
| :--- | :--- |
| `cell` | 聚合后的细胞标识符（缺失 Sample Barcode 的背景可能为空） |
| `reads` | 该微球/液滴对应的转录组 Read 数 |
| `gene` | 检测到的基因种类数 |
| `umi` | 检测到的转录本分子（UMI）总数 |
| `is_cell_barcode` | **真实细胞标记**（`1` 或 `True` 表示判定为有效细胞；`0` 或 `False` 为背景） |
| `barcode` | 原始细胞条形码（保留 Sample Barcode 标识后缀） |

> **下游使用提示**：在 R 或 Python 中读取该表时，务必根据 `is_cell_barcode` 列筛选真实细胞，不可将全表直接视作细胞。

### 4. 逐样本专属目录 (`per_sample_outs/<sample>/`)

每个样本在此目录下获得一套与标准单样本 RNA 分析完全等价的完整交付物：

* **专属 HTML 报告 (`<sample>_scRNA_report.html`)**：该样本专属的细胞质控曲线（Barcode Rank Plot）、UMAP/t-SNE 细胞分群图、高表达 Marker 基因热图；
* **专属表达矩阵**：包含该样本独立的 MEX、H5 与包含该样本聚类信息的 H5AD；
* **专属 BAM 比对文件 (`<sample>_alignments.bam`)**：仅包含该样本真实读段的比对文件，可直接载入 IGV 查阅特定基因转录本。

## 核心指标与统计口径说明 <a id="核心指标说明"></a>

为避免在多样本混合分析中产生误解，C6 的指标分母遵循以下严谨定义：

| 指标项 | 统计范围与口径说明 |
| :--- | :--- |
| **Assigned Reads** | 分配到该样本的实际 Read Pairs 数（以 Sample Barcode 识别为准，非全库原始 Reads） |
| **Mean Reads per Cell** | 样本内平均细胞读段数 = `Assigned Reads` / `Cells`（细胞数为 0 时显示为 N/A） |
| **Fraction Reads in Cells** | 该样本细胞内可信转录组 Reads 占该样本全部有效条形码转录组 Reads 的比例 |
| **Mapping Quality** | 计算分母为该样本的 All Reads，绝不混入全局或非细胞读段的比例 |
| **cDNA Valid Barcodes** | 当 Assigned Reads > 0 时稳定显示为 100%（描述已分配入该样本的集合） |
| **文库级指标 (Q30 / Valid UMI)** | 反映全库共享测序质量，不能解释为样本独立 QC；指标表中统一标注为 `cDNA QC scope` |
| **Sample Barcode 有效率** | 统计 Oligo 中成功匹配至设计 Sample Barcode 白名单的比例，由真实统计得出 |
